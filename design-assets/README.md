# Design assets — MONGIL: STAR DIVE image hunt (2026-10-30)

Everything sourced for the site's design work, in one place. Full provenance —
source link and use status for every file — is in `LOG.md` next to this file.
Nothing here is wired into the site build; pull what a design needs into the
site's own asset folders.

## Folders

- `characters/official-site/` — 17 full-body splash portraits (2000×2000 PNG,
  clean cutouts, no watermarks) from the official site. USABLE.
  Mina, Narae, Nagi, Verna, Cloud, Ophelia, Francis, Esther, Flare, Reina,
  Daisy, Penny, Jiwon, Gabi, Yeonhwa, Leeho, Sangun.
- `characters/media-hub/` — the same 15 characters as Netmarble Media Hub
  press PNGs (3000×3000). Game logo + nameplate baked in bottom-left,
  copyright line bottom-right, on white. Resolution masters; the
  official-site versions are cleaner for tier rows. USABLE (non-commercial,
  unmodified, credited, with the site's not-official disclaimer).
- `characters/forum/` — official forum profile cards (JPG, ~1480×2140) and
  animated in-game model GIFs for Chloe, Isabella, Vivian, Brisshell, Mabel,
  Narae, Nagi, plus Verna: Summer Dive! and Francis: Summer Dive!. USABLE.
- `characters/wiki-exception/` — Benjamin, Sera, Ellie, Bonnie, Angel.
  No Netmarble-published portrait exists for these five anywhere.
  EXCEPTION (Tom's explicit call, 2026-10-30): third-party database art
  (Kaiden.gg bust portraits + cross-check files), game-derived, NOT
  Netmarble-published. Swap out if official art ever appears.
- `backgrounds/` — 4 official world-art stills (1440×808 PNG) for mode and
  hero backgrounds.
- `key-visuals/` — 9 key visuals / concept art as DESIGN COPIES: resized to
  2560px on the long edge, JPEG. The print-resolution masters (up to
  15000×8299; three files exceed GitHub's 100MB per-file limit) stay in the
  hunt archive off-repo. Ask before using one at full size.
- `pr-art/` — newsroom and trailer art: Summer Dive header (1920×1080) +
  newsroom shot, KR trailer thumbnails for Mabel and Brisshell (NEEDS
  CHECKING — banner use only), a Chloe PR screenshot, and the v1.4
  "Ashen Cradle Lullaby" Isabella key art at 708×398 (low-res; a
  higher-resolution official copy is still wanted).
- `contact-sheets/` — quick overview sheets of the portrait sets.

## Rules that travel with these files

- Screenshots and crops from the game are allowed; no ripped or extracted
  game files, no datamined or unreleased content.
- Do not modify an image in a way that falsifies it. Animate *around* art,
  never transform it. No Live2D/Spine rigging of official art without Tom's
  explicit approval.
- The site is non-commercial and carries a "not official" disclaimer.
- Not included: the Media Hub source zips and the hunt's scrape data
  (duplicates / working files), and one download-test PNG.
