## Bottom line for the build decision

- A full 29-character list IS buildable, but only as: per-mode views (Conquest / Rift),
  a consensus Overall with Solid / Contested / Speculation tags, and an explicit
  Unranked row for Vivian + the Story-only units. A single definitive ranking is
  NOT supported by the data.
- 6 of 29 characters have no endgame-mode placement in the newest per-mode source.
- Still missing before a build: Kaiden's actual placements (needs a live-browser pass),
  and any second current source for Chloe / Isabella / Brisshell / Mabel / Nagi.
